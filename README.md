# Qtec Task Management System

This repository currently contains the implementation plan for the Qtec practical assessment.

Start here:

- [System architecture and roadmap](docs/system-architecture-and-roadmap.md)

The recommended first build is a focused Laravel task management system with:

- Task CRUD
- Status tracking
- Status filtering
- Controller + Service + Repository structure
- Basic feature tests
- Clear documentation

The plan is intentionally optimized for the assessment's stated scope, time limit, and evaluation criteria.
